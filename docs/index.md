title: Counting Arnold's Meanders
---

*In how many ways can a river cross a straight road *n* times?* V. I. Arnold asked in 1988. The
river comes in from the south, crosses the road *n* times without crossing itself, and leaves
to the east. The answers start 1, 1, 1, 2, 3, 8, 14, 42, 81, 262, … (OEIS
[A005316](https://oeis.org/A005316)), and no formula is known.

This project defines the numbers in the [Lean 4](https://lean-lang.org/) proof assistant and
computes them with algorithms that are **proved** to count exactly what Arnold asked: a search
with a parity rule, and a transfer matrix. Every value up to *n* = 13 is checked by Lean's
kernel and every value up to *n* = 24 by compiled Lean code.
